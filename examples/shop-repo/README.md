# shop-repo — the code the example documentation describes

`shop.docs.json` and `auth.docs.json` anchor claims to files in here, so the
bundled demo shows a document whose anchors actually verify rather than a wall
of "unverifiable".

It ships with the package for that reason: `vibex demo` has to work from a fresh
install, and a product about trustworthy documentation cannot open on red.

Nothing here runs. It is the shape of a NestJS service, not a working one.
